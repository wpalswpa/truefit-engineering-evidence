# 이 저장소의 범위

트루핏 팀 저장소는 비공개다. 이 저장소는 **그 코드의 사본이 아니라**,
공개할 수 있는 범위에서 설계와 검증 방법을 재현 가능한 최소 예제로 다시 쓴 것이다.

## 들어 있는 것

| 경로 | 내용 |
|---|---|
| `validator.py` | LLM 응답 검증 규칙만 최소 형태로 재작성 |
| `tests/` | 불변식 10개. 표준 라이브러리만으로 실행 |
| `examples/` | 입력 원문 · 모델 응답 · 검증 결과 한 벌 |
| `docs/decisions/` | 설계 결정 2건 — 대안·채택 이유·남은 제약 |
| `evidence/` | 비공개 저장소에서 기록된 릴리스 검증 결과 |

## 들어 있지 않은 것

계약·예약·정산 도메인 로직, 인증, 데이터베이스 스키마, 화면, 배포 설정.
팀 프로젝트의 산출물이라 공개 대상이 아니다.

## 원본과의 관계

원본은 Python 3.12 / Flask / SQLite / Waitress 위에서 동작하고
상품 → 신청 → 예약 → 양측 이용 확인 → 회차 정산·미사용분 반환 흐름을 다룬다.
여기 옮긴 것은 그 흐름 중 **LLM 응답이 제품 상태로 들어가기 직전의 관문** 하나다.

원본 검증 기록은 `evidence/gate-summary.json` 에 출처와 함께 적었다.
그 수치는 이 저장소에서 재현되지 않는다.
