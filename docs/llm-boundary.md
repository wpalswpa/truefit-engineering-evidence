# LLM에 맡긴 일과 맡기지 않은 일

트루핏은 운동 수업의 계약·예약·이용 확인을 기록하고 정산하는 서비스다.
LLM은 그중 한 곳에만 들어간다 — 사람이 쓴 설명에서 확인할 쟁점을 골라내는 일.

```
계약 원문 ──▶ LLM 구간 선택 ──▶ 서버 응답 검증 ──▶ 원문 인용
  세그먼트      gpt-4.1-mini       스키마·ID 범위      서버가 직접 추출
  ID 부여       kind/first/last    잘못된 응답 거부    생성 문장 미사용
                                        │
                                  검증 실패 → 원문 확인 경로 안내
```

## 모델이 하는 일

- 원문의 어느 구간이 어떤 쟁점인지 **고른다**. 번호로 답한다.

## 모델이 하지 않는 일

| 항목 | 누가 정하나 |
|---|---|
| 금액 | 계약 스냅샷과 정산 규칙 |
| 노쇼 귀책 | 양측 확인 기록 |
| 회차 차감 | 이견이 있으면 보류, 규칙이 처리 |
| 인용문 문장 | 서버가 원문에서 추출 |

확정적이어야 하는 값은 모델 판단에서 분리했다. 모델이 틀려도 금액이 바뀌지 않는다.

## 왜 이렇게 나눴나

분쟁 화면이기 때문이다. 회원과 센터의 주장이 갈릴 때 쓰는 기능이라,
"AI가 그렇게 판단했다"는 근거가 될 수 없다. 화면에 올라가는 것은
**원문 어디에 무엇이 적혀 있는지**여야 하고, 그 판단은 사람이 한다.

자세한 선택 근거는 `decisions/001-source-span-extraction.md`.
